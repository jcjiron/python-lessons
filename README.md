# python-lessons

Tutorial de estilos de programación en Python, usando un mismo proyecto ancla
(**Sistema de Pedidos**) reescrito bajo 11 enfoques distintos.

## Proyecto ancla

Un sistema chico que: recibe los ítems de una orden, aplica reglas de
descuento/cupón, valida stock disponible y genera un recibo con el total.
Suficiente carne para que cada estilo se sienta distinto, suficientemente
chico para no perdernos.
